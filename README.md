# ASMR 本地字幕

**v1.0.0 · Windows · 日语音频 → 简体中文字幕**

边听日语 ASMR 或其他日语音频，边在桌面上查看中文翻译。

ASMR 本地字幕通过 Windows 播放回环采集**电脑正在播放的声音**，在本机完成日语语音识别与中文翻译，并将结果显示在可自由调整的透明悬浮字幕窗中。耳机播放同样适用，无需将音频上传至在线翻译服务。

**首次安装需要联网下载依赖和模型；安装完成后，正常字幕识别与翻译无需云服务账号或 API Key。** 字幕需要经过收音、识别和翻译，因此会有一定延迟，并非与播放器时间轴严格同步的现成字幕。

## 功能特点

- **播放回环采集**：识别正在通过 Windows 耳机或扬声器播放的日语声音，不需要手动录制或导入音频文件。
- **透明悬浮字幕**：无标题栏，可跨屏拖动、从边缘缩放；支持透明背景、字体颜色、细描边和柔和阴影。主界面采用淡粉色渐变风格。
- **译文或中日双语**：可只显示简体中文，也可同时显示日语原文与中文译文；支持译文逐步显示和隐藏状态提示。
- **本地多种推理模式**：提供自动、CUDA、CPU＋显卡（均衡）、CPU＋显卡（省显存）、仅 CPU、Vulkan 六种翻译模式。日语识别与中文翻译分别运行。
- **自定义翻译词库**：默认提供作者整理的 **312 条保守词条**，支持 JSON 导入、界面编辑与长期保存。
- **双语字幕导出**：可手动导出中日双语 SRT；默认不录制音频，也不自动保存字幕。

为避免处理速度持续落后于播放进度，程序会在字幕积压过多时停止接收声音，并明确提示，而不是无限累积待翻译内容。

## 运行要求

| 项目 | 要求或建议 |
| --- | --- |
| 操作系统 | Windows 10 / 11，**64 位 x64** |
| Python | **Python 3.12 x64**，安装时包含 Tcl/Tk 与 Python Launcher |
| 内存 | 建议 **16 GB 或以上** |
| 磁盘空间 | 首次安装建议预留约 **25 GB**，供模型、分段下载文件和运行环境使用 |
| NVIDIA 显卡 | 建议使用 CUDA；显卡驱动需支持 **CUDA 12.4**，**8 GB 及以上显存**更宽裕 |
| AMD / Intel 等显卡 | 可尝试 Vulkan，具体取决于显卡与驱动支持 |
| 无可用 GPU | 可以使用纯 CPU，但速度取决于处理器、内存带宽与台词密度 |
| 音频输出 | 播放器应使用**共享音频输出**；WASAPI 独占等模式可能无法被回环采集 |

Python 安装包可从 [Python 官方网站](https://www.python.org/downloads/windows/) 获取。

目前主要在 **Windows 11 / i7-14650HX / 32 GB 内存 / RTX 4060 Laptop 8 GB** 环境下验证。其他配置的翻译速度与流畅度可能不同。

> **注意**：即使提供 `.exe` 启动器，本项目仍需按以下步骤安装 Python、依赖和本地模型，并非开箱即用的单文件程序。

## 安装与启动

1. 下载项目压缩包，**完整解压到具有写入权限的目录**，不要直接在 ZIP 压缩包内运行脚本。
2. 安装 **Python 3.12 x64**，确认安装组件包含 Tcl/Tk 和 Python Launcher。
3. 双击 **`安装环境与模型.cmd`**，等待环境与模型准备完成。脚本会在项目目录创建 `.venv`、安装固定版本依赖，并下载语音识别模型、翻译模型和 `llama.cpp` 运行时；检测到 NVIDIA 显卡时，还会额外准备 CUDA 运行时。
4. 安装完成后，双击 **`ASMR本地字幕.exe`** 启动程序；也可以运行 **`启动本地字幕.cmd`**。

首次下载的模型与运行时合计约 **6–7 GB**，Python 依赖下载另计。安装中断后可重新执行 `安装环境与模型.cmd`：已完成的文件通过 SHA256 校验后会复用，**不要同时运行多个安装窗口**。

安装脚本仅向项目内的 `.venv` 安装 Python 包。不要复制其他电脑或目录中的虚拟环境；如果移动项目后 Python 环境无法正常启动，可重命名原 `.venv` 并重新安装，原有模型和个人设置可保留。

### 开始使用

1. 打开程序，等待主界面显示**“本地模型已就绪”**。此时程序尚未开始采集声音。
2. 选择当前实际出声的耳机或扬声器。设备名称末尾带有 **`[Loopback]`** 的选项表示播放回环。
3. 点击 **“开始接收播放声音”**，然后播放日语音频，查看悬浮窗中的译文。
4. 在**“悬浮字幕设置”**中调整字幕样式与位置。透明模式下可以按住文字拖动；如需拖动空白区域或改变窗口大小，可先暂时关闭透明背景。
5. 结束收听时点击主界面的停止按钮。切换作品时建议使用 **“新作品 / 清空”**；关闭主窗口会释放本程序的音频设备和模型进程。

更详细的操作与排错说明见 [使用说明](使用说明.md)。

## 翻译模式怎么选

六种模式控制的是**中文翻译的运行方式**；日语语音识别作为独立流程运行。选择时可优先考虑自己是否需要给其他程序保留显存。

| 模式 | 适合场景 |
| --- | --- |
| **自动** | 初次使用，不确定该选哪种模式时 |
| **CUDA** | NVIDIA 显卡显存比较充足，优先追求翻译速度 |
| **CPU＋显卡（均衡）** | 边听边运行游戏，希望给游戏留出部分显存 |
| **CPU＋显卡（省显存）** | 显存较紧张，希望进一步减少显卡占用 |
| **仅 CPU** | 希望中文翻译不占用 GPU，或没有适合的显卡运行时 |
| **Vulkan** | AMD / Intel 显卡，或需要尝试另一种 GPU 运行时 |

两档 CPU＋显卡混合模式需要先安装 **CUDA 运行时**。其中，均衡模式将 **24 层**放在显卡上，省显存模式放 **16 层**。混合模式主要是为了减少显存占用；如果显存充足，全 CUDA 通常更快。

CPU 翻译线程数可先尝试 **8**，为同时运行的日语识别留出资源。更改翻译设备或线程数后，请**保存作品设置并重新启动程序**。

如需从 Vulkan 切换到 CUDA，先在项目目录执行 `install.ps1 -Backend CUDA`，再到界面中选择 CUDA 或混合模式。

## 自定义词库与字幕导出

### 默认词库

首次运行会载入 `词库_保守版_ja_zh.json`，内含作者整理的 **312 条保守词条**。默认发布包仅包含这一份词库。

你可以在界面中修改词条，或导入自己的 JSON 词库。完成后点击 **“保存作品设置”**，词库与作品相关设置会保存在项目目录下的 `作品设置.json`。

重新打开程序、切换作品或使用“新作品 / 清空”，都不会自动删除已保存的词库。重新运行安装脚本也不会覆盖已有的自定义词库设置。

这份默认词库允许按本项目的 MIT 许可证使用、修改和分发。

### 导出字幕

需要保留本次的识别和翻译结果时，可以手动导出**中日双语 SRT 文件**。程序不会自动生成字幕文件，也不会自动录制或保存音频。

SRT 时间以**本次开始接收声音**为基准，不会在播放器快进、跳转或切换曲目后自动重新校准。因此，导出的字幕适合保留和后续整理；如果要与原音频精确对齐，可能仍需手动调整时间轴。

## 本地处理与隐私

- **识别和翻译在本机执行**，正常字幕运行无需云服务账号或 API Key。
- **首次安装仍需联网**，用于下载依赖、模型及推理运行时；安装脚本下载软件文件，不上传播放音频。
- 正常运行期间，Python 层将网络访问限制为本机回环；本地翻译服务监听 `127.0.0.1`，并在每次启动时使用临时口令。这是应用层设计，不等同于操作系统级防火墙隔离。
- 默认**不自动保存声音或导出字幕**；词库、作品背景和外观设置仅在用户点击保存后写入本地。

## 已知限制与常见问题

**为什么字幕会比声音慢？**  
程序必须先收音，再进行日语识别和中文翻译，因此存在处理延迟。这不是读取播放器自带字幕的工具，也不保证逐句严格同步。

**为什么耳机有声音，却没有识别结果？**  
请确认选择的是实际播放设备对应的 `[Loopback]`，并检查播放器是否启用了 WASAPI 独占等不能正常回环采集的输出方式。

**为什么有些耳语、呼吸或拟声没有被正确翻译？**  
轻声、耳语、呼吸声与拟声词本来就可能被语音识别误判；翻译也可能误解语境或遗漏内容。程序会保守过滤部分长串无意义音节，但无法保证所有内容都识别准确。

**为什么程序提示字幕积压并停止接收？**  
这表示当前处理速度已无法跟上音频播放。可尝试降低其他程序的显卡负载、缩短单次收音长度、切换更合适的推理模式或放慢播放速度。程序会主动停止并提示，避免字幕延迟无限累积。

**导出的 SRT 为什么与原音频时间不一致？**  
SRT 按本次接收开始计时，不会自动识别播放器跳转、暂停或换曲造成的时间轴变化。

## 高级安装与运行时切换

如需手动指定推理运行时，或安装脚本未能自动找到 Python，可在项目目录打开 PowerShell：

```powershell
# 默认：NVIDIA 使用 CUDA，其他显卡使用 Vulkan
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

# 按硬件情况指定运行时（三选一）
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Backend CUDA
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Backend Vulkan
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Backend CPU

# Python 无法自动找到时，指定本机 Python 3.12 x64 的路径
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -PythonPath "C:\path\to\python.exe"
```

模型来自其原作者公开的下载地址，固定版本和 SHA256 校验值记录在 `setup_runtime.py`、`setup_latency_runtime.py` 和 `runtime/whisper-checksums.json` 中。**项目发布包不包含模型权重**，需在首次安装时自行下载。

## 源码与开发

主要代码入口：

| 文件 | 用途 |
| --- | --- |
| `app.py` | 应用入口 |
| `realtime_core.py` | 音频接收、字幕处理与本地推理流程 |
| `alpha_subtitles.py` | 透明悬浮字幕的绘制与显示 |
| `launcher/build.ps1` | 可选：从附带的 C# 源码重建启动器 |

依赖安装完成后，可以在**不下载模型、不采集声音**的情况下运行已有测试：

```powershell
.\.venv\Scripts\python.exe -m unittest test_core test_glossary test_release
```

重新生成源码与安装脚本压缩包：

```powershell
.\.venv\Scripts\python.exe build_release.py
```

生成结果位于 `dist/`。打包脚本按照公开文件清单收集内容，并排除个人设置、模型、虚拟环境与日志。
